# Oman Labour Law — reference for HR

The Labour Law issued by Royal Decree 53/2023 (25 July 2023, Official Gazette 1504, 30 July 2023),
which replaced the 2003 law. Keep this as the reference whenever an HR question or a portal rule
depends on the law. Ministerial decisions issued under it (e.g. 618/2024, 619/2024) can add detail.

| File | What it is |
|---|---|
| `oman-labour-law-RD-53-2023-ar-en.pdf` | Full law, Arabic and English side by side (edition by Dr. Asad Alhadhrami Law Firm), 88 pages, Articles 1–150 |
| `oman-labour-law-RD-53-2023-en.txt` | The English column as plain text, for searching (`grep -n -i "annual leave"`) |
| `oman-labour-law-2023-check.md` | How the portal's leave rules were checked against the law |

The Arabic text is the official one; the English is a translation. Before relying on an article for a
decision about a person, read it in the PDF (and ask the legal adviser where it matters).
